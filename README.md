# Deep Learning-Based Sleep Disorder Detection Using EEG Signal Analysis

## Project Overview

This project focuses on automatic multi-class sleep disorder detection using EEG signals. The proposed system uses a deep learning model based on CNN and BiLSTM to learn spatial and temporal patterns from EEG data and classify different sleep-related conditions.

## Sleep Disorder Classes

The model classifies EEG signals into four categories:

- Normal
- Insomnia
- Sleep-Disordered Breathing (SDB)
- Narcolepsy

## Dataset

The project uses EEG recordings from the CAP Sleep Database. The EEG signals are processed and divided into suitable segments before being provided to the deep learning model.

> The original EEG dataset is not included in this repository because of its large size.

## Project Workflow

1. EEG data collection
2. Signal preprocessing
3. Filtering and segmentation
4. Feature/data preparation
5. CNN-based spatial pattern learning
6. BiLSTM-based temporal pattern learning
7. Model training
8. Performance evaluation
9. Sleep disorder classification
